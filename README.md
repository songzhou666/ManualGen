# ManualGen - 智能业务分析与操作手册生成专家

ManualGen 是一款面向 AI 编码助手的 Skill，专为自动生成高质量用户操作手册而设计。它能够深入理解项目业务流程、功能关系和用户场景，生成面向运营人员、销售人员、客户的用户版操作手册。

## 核心能力

- **功能点清单** -> 自动提取项目的功能模块和 API
- **状态机分析** -> 分析业务流程的状态流转
- **数据上下游** -> 追踪数据创建、流转和消费关系
- **完整性评估** -> 评估功能覆盖率和文档缺失项
- **单版用户手册** -> 输出面向用户的可交付文档

## 架构特色

- **状态机驱动**: 12阶段自动推进，从探索到审核一条龙完成
- **多 Agent 协作**: Master Controller 统领 7 个专业 Agent 分工协作
- **接力棒持久化**: 支持跨 Session 续跑，中断不丢失进度
- **验证链阻断**: 每阶段产物必须通过验证才能进入下一阶段
- **隐私保护**: 全流程敏感数据过滤，确保信息安全
- **按需加载**: 只加载当前阶段所需的 Chunk，保持上下文精简

