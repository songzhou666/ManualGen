# 状态机自动驱动说明

> ManualGen 采用**状态机自动驱动**模式，激活后自动沿状态机推进，无需手动输入命令。

## 执行流程

```
激活 → 强制入口清单 → 读取接力棒 → 确定当前状态 → 执行阶段任务 → 更新接力棒 → 自动进入下一阶段
```

| 步骤 | 说明 |
|------|------|
| 1 | 用户激活 ManualGen 后，立即执行强制入口清单 |
| 2 | 读取接力棒，确定当前状态 |
| 3 | 如果状态为 START → 标记为 EXPLORE，开始第一阶段 |
| 4 | 如果状态为 X → 直接从 X 阶段续跑 |
| 5 | 执行当前阶段任务，写入产物 |
| 6 | 更新接力棒，自动进入下一阶段 |
| 7 | 重复步骤 5-6，直到 CONFIRM（等待用户确认）或 DONE |

## 各阶段简述

| 阶段 | 职责 |
|------|------|
| EXPLORE | 理解项目业务全貌 |
| EXTRACT | 提取功能/API/路由/页面 |
| ANALYZE | 流程+状态机+边界+数据上下游 |
| GAP | 完整性评估+项目形状报告 |
| CONFIRM | 展示摘要等待用户确认 |
| RESOLVE | 冲突检测与解决 |
| WRITE | 按模板编写模块文档 |
| REFINE | 逐模块精炼补全深度内容 |
| REFERENCE_CHECK | 交叉引用+术语一致性检查 |
| INTEGRATE | 整合为完整手册 |
| AUDIT | 独立盲审（6维度） |
| TODO_RESOLVE | 统一解决待办项 |
| JUDGE | 判定文档是否可发布 |

## 状态查询

在任意时刻，AI 会自动在回复中输出 `当前状态：[阶段名]，下一步：[操作]`，您可以通过它了解当前进度。
