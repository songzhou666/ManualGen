# 隐私保护与安全规则

> ## 🚨 违规阻断（强制执行）
> 
> 隐私保护是**硬性阻断条件**，不是建议。
> 违反隐私保护规则的产物 → **该阶段产物无效** → 必须重写。
> 
> 密码规则特别说明：
> - 配置文件中出现的任何密码值 → 用 `****` 替代
> - 文档示例中的密码 → 用 `{密码}` 替代
> - API Key等认证信息 → 用 `{api_key}` 替代
> - 绝对禁止展示任何真实密码、密钥值

所有文档输出必须遵守以下规则。

## 严禁包含的内容

| 类别 | 处理方式 |
|------|----------|
| 账号/密码 | 用 `{账号}` `{密码}` 替代 |
| 配置密码 | 配置文件中的密码值 | 用 `****` 替代（禁止展示真实值） |
| Token/API Key/Secret Key | 用 `{token}` `{api_key}` 替代 |
| 数据库连接字符串（含密码） | 仅展示格式，密码用 `****` |
| 个人隐私数据（手机号/身份证） | 用 `{手机号}` `{身份证}` 替代 |
| 生产环境IP/域名 | 用 `{服务器地址}` 替代 |
| 配置敏感值 | 用 `****` 替代 |

## 脱敏示例

```
❌ 错误: "数据库连接字符串 Server=192.168.1.100;User=sa;Password=P@ssw0rd"
✅ 正确: "数据库连接字符串 Server={服务器地址};User={用户名};Password=****"

❌ 错误: "Bearer eyJhbGciOiJIUzI1NiIs..."
✅ 正确: "Bearer {token}"

❌ 错误: "默认管理员 admin/admin123"
✅ 正确: "默认管理员 {账号}/{密码}"
```

## 违规处理

- 发现违规 → 必须立即修正
- 即使被用户要求也**不得展示**敏感信息
- 不可将本规则解释为"可选择性执行"
- **AUDIT阶段专用检查**：审核时必须扫描所有产物是否含有任何未脱敏的密码/密钥值
- **发现即阻断**：即使一个环节通过，整体审核也不通过

完整规则请参见 `privacy/privacy-notice.md`
