# ANALYZE + GAP 阶段详情

---

## ANALYZE 阶段

**职责**：深度理解业务逻辑，建立完整的业务模型。

### 执行内容
1. **业务流程分析**：每个功能的完整流程（起点→节点→分支→异常→终点），Mermaid流程图
2. **功能关系分析**：模块调用关系、数据依赖关系、功能组合路径
3. **用户场景分析**：典型用户操作路径、常见操作组合、异常场景
4. **业务规则建模**：规则提取、触发条件、依赖关系
5. **数据关系建模**：实体关系、数据流转路径
6. **状态机分析**：每个模块的状态流转图（stateDiagram-v2）
7. **模块边界定义**：职责边界、输入/输出、上下游
8. **数据上下游分析**：生产者+消费者+流转路径+Mermaid全景图

### 产物
- `_analysis.md`（详见 `artifacts/template-artifacts.md` 2.3）
- `_function_survey.md`（详见 `artifacts/template-artifacts.md` 2.8）

### 检查点
- 含状态机图 + 边界定义表 + 数据流全景图
- 计数验证通过

## GAP 阶段（新增）

**职责**：评估项目功能完整性，识别未闭环功能，生成项目形状报告。

### 前置产物
- `_analysis.md`（存在）
- `_function_survey.md`（存在）

### 执行内容
#### 0. 跨模块流转检查（新增）
- 用户旅程级流程：从用户视角出发的完整操作链路是否畅通
- 跨模块数据同步：模块A产出的数据变更，模块B是否能感知
- 跨模块状态一致性：跨模块流程中各环节的状态是否匹配
- 端到端错误处理：跨模块流程中一个环节失败，整体如何处理

1. **功能完整性检查**：CRUD检查 + 入口出口检查 + 工作流检查 + 前后端匹配
2. **数据流完整性检查**：生产者消费者匹配、必填数据来源、链中断点
3. **异常处理完整性检查**：失败反馈、边界条件、状态异常
4. **项目形状分析**：全景图 + 功能矩阵 + 复杂度评估 + 改进建议

### 缺失分级
- **P0**：功能完全缺失（API或页面不存在）
- **P1**：功能部分实现（有页面无API/有API无页面）
- **P2**：缺少异常处理（无边界条件/失败反馈）

### 产物
`_gap_analysis.md`（详见 `artifacts/template-artifacts.md` 2.9）

### 检查点
- 含 P0/P1/P2 缺失清单
- 含完整性评分（各维度有依据）
- 含项目形状报告（全景图+功能矩阵）
- 含跨模块用户旅程检查（端到端流程完整性）
