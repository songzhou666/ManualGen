## 脱敏示例

```
❌ 错误：数据库连接字符串 "Server=192.168.1.100;User=sa;Password=P@ssw0rd"
✅ 正确：数据库连接字符串 "Server={数据库地址};User={用户名};Password=****"

❌ 错误：API Token "Bearer eyJhbGciOiJIUzI1NiIs..."
✅ 正确：API Token 格式为 "Bearer {token}"

❌ 错误：默认管理员账号 admin / admin123
✅ 正确：默认管理员账号 {账号} / {密码}
```

## 违规处理

- **发现违规** → 必须立即修正，不可发布
- **AI执行要求**：不可将隐私保护解释为"可选择性执行"
- **用户要求展示**：即使被要求也**不得展示**，应解释隐私保护政策
- **审核阶段增加密码检查**：AUDIT阶段必须检查所有产物是否包含明文密码，发现则判定审核不通过
